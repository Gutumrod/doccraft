# DocCraft — Public Pilot Observation & Interview Guide

> **Purpose:** เก็บ evidence สำหรับ PV Gate โดยไม่ชี้นำผู้ใช้
> **Mode:** No telemetry / structured manual observation
> **Privacy:** ใช้ Pilot ID เท่านั้นใน repository

## 1. Before Session

Record only:
- Pilot ID
- segment: freelancer/contractor, custom workshop/service shop, or micro-SME
- device class and browser
- whether this is first use or return use

Do not pre-teach the flow unless the user is blocked. Any assistance given must be recorded because it affects activation evidence.

## 2. Observe First-Use Core Loop

Ask the participant to create a document they would realistically use, while using non-sensitive/sample data if screen recording or shared observation is involved.

Observe without leading:
- can they choose the document type
- can they enter business/customer/item data
- do they understand adjustments/tax fields they need
- do they find Preview
- do they reach Print/Save through the browser dialog
- where do they hesitate, ask for help, or abandon

## 3. Post-Session Questions

Ask in this order to reduce leading:
1. วันนี้ใช้ DocCraft ทำอะไร และจุดไหนง่าย/ยากที่สุด?
2. ถ้าต้องทำเอกสารแบบนี้อีก พรุ่งนี้หรือสัปดาห์หน้า คุณจะกลับมาใช้ไหม? เพราะอะไร?
3. มีอะไรที่ต้องพิมพ์ซ้ำหรือทำซ้ำจนรำคาญไหม?
4. ถ้าเปิดอีกเครื่องหนึ่ง คุณคาดหวังว่าจะเห็นอะไรจากเครื่องเดิม?
5. การเก็บเอกสารไว้เฉพาะใน Browser เครื่องนี้เป็นปัญหาสำหรับงานจริงหรือไม่? ขอเหตุการณ์จริงหรือสถานการณ์ที่เคยเจอ
6. คุณต้องการย้อนดูเอกสารเก่า/history บ่อยแค่ไหน และเพื่อทำอะไร?
7. รายชื่อลูกค้า/สินค้า/บริการที่ใช้ซ้ำ มีอะไรที่อยากเลือกกลับมาใช้แทนพิมพ์ใหม่?
8. ถ้ามีสิ่งหนึ่งที่ทำให้คุณเลิกใช้ DocCraft จะเป็นอะไร?

Only after concrete pain is established:
9. ถ้าฟีเจอร์นั้นแก้ pain นี้ได้จริง คุณมองว่ามีมูลค่าพอจะจ่ายหรือไม่? เพราะอะไร?
10. คุณจะเทียบมันกับวิธี/เครื่องมืออะไรที่ใช้อยู่ตอนนี้?

## 4. Return-Use Check

A later follow-up should verify behavior, not intention:
- did the participant actually return
- did they edit an existing draft or create another document
- what triggered the return
- did local-only storage create friction
- did repeated data entry create friction

Intention alone is not repeat-use evidence.
