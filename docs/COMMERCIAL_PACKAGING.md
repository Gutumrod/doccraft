# DocCraft — Commercial Packaging Contract

> **Status:** Pre-Pricing Commercial Contract
> **Date:** 2026-08-22
> **Rule:** Packaging may not claim capability that has not passed its roadmap gate

## 1. Packaging Principle
Free V1 is the intended local-first core and becomes a validated baseline only after Phase 6 + Pilot Validation evidence. Paid packaging must charge for incremental value such as cloud persistence, reusable data, cross-device workflow or later validated capabilities—not by crippling the basic document core retroactively.

## 2. Free Package Baseline
Free may include only capabilities that actually pass Phase 1–6 gates, including no-login document creation, local persistence/JSON backup, native print and document PromptPay QR when Phase 5 passes.

## 3. Pro Candidate Value
Candidate Pro capabilities only after PV Gate passes and the relevant Phase 7 capability passes implementation gate:
- account + cloud sync
- cross-device document history
- reusable customers/products
- cloud-backed recovery/version history if implemented

No candidate is a selling point before implementation and gate evidence.

## 4. Later Add-On Candidates
Lifecycle conversion, reports/Excel, themes/templates, E-Sign/public approval links require Phase 9 PRD extension and may become bundled/add-on features only after validation.

## 5. Pricing Status
`฿290/month`, `฿2,490/year`, `฿1,490 lifetime` remain hypotheses, not approved public prices.
## 6. Package Contract Required Before Sale
ก่อนประกาศราคา ต้องกำหนดเป็นตารางจริง:
- capability per package
- usage/storage limits ถ้ามี
- monthly/yearly billing terms
- downgrade behavior
- grace/expiry behavior
- data access/export after downgrade/cancel
- support entitlement

## 7. Lifetime Guardrail
ห้ามขาย lifetime deal จนมี:
- definition ว่า lifetime ของอะไร/ใคร
- entitlement persistence rule
- long-term service/storage cost model จากข้อมูลจริง
- closure/discontinuation policy

## 8. Launch Gate
Paid package เปิดได้เมื่อ:
- `PRODUCT_VALIDATION_PLAN.md` มี evidence ว่าคนยอมจ่ายเพื่อ value นั้น
- Phase 7/8 capability ที่เกี่ยวข้องผ่าน gate
- `CUSTOMER_LIFECYCLE_AND_BILLING_POLICY.md` และ `SERVICE_OPERATIONS.md` พร้อม
- public terms/pricing ตรงกับ billing implementation จริง
