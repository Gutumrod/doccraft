# DocCraft — Public Pilot Participant Brief

> **Production:** `https://dc01.wstera.com`
> **Pilot type:** Free controlled Public Pilot

## สิ่งที่อยากให้ลอง

ใช้ DocCraft ทำเอกสารที่ใกล้กับงานจริงของคุณ 1 ฉบับ ตั้งแต่เริ่มกรอกข้อมูลจนถึง Preview และเปิดหน้าต่าง Print/Save ของ Browser

ไม่ต้องพยายาม “ทดสอบให้ผ่าน” ถ้าตรงไหนงง ช้า หาย หาไม่เจอ หรือไม่ตรงกับวิธีทำงานจริง ให้หยุดและบอกตรงนั้นได้เลย เพราะสิ่งเหล่านี้คือข้อมูลที่ Pilot ต้องการ

## ข้อควรรู้ก่อนใช้

- ไม่ต้องสมัคร/Login
- draft เก็บใน Browser ของเครื่องที่ใช้อยู่
- ยังไม่มี Cloud Backup หรือ sync ข้ามเครื่อง
- PromptPay QR บนเอกสารไม่ได้ยืนยันว่าได้รับเงินจริงแล้ว
- ผลการพิมพ์ขึ้นกับ Browser/OS/เครื่องพิมพ์; ก่อนพิมพ์งานจริงควรตรวจ Paper size และ preview
- DocCraft ไม่ใช่ระบบบัญชีหรือคำรับรองด้านภาษี

## ความเป็นส่วนตัว

ไม่จำเป็นต้องส่งไฟล์เอกสารจริง ข้อมูลลูกค้า Tax ID PromptPay identifier หรือข้อมูลส่วนตัวให้ทีม Pilot ถ้าไม่จำเป็นต่อการแก้ปัญหา

## หลังลองใช้

ทีม Pilot จะถามสั้น ๆ ว่า:
- ใช้ทำเอกสารอะไร
- จุดไหนง่าย/ยาก
- จุดไหนต้องถามหรือหยุด
- จะกลับมาใช้กับงานจริงอีกหรือไม่ และเพราะอะไร

ถ้ากลับมาใช้ในวันหรือสัปดาห์ถัดไป ให้แจ้งทีม Pilot ด้วย เพราะการใช้งานซ้ำเป็นหลักฐานสำคัญกว่าความเห็นว่า “น่าจะใช้”
