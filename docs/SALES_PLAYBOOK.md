# DocCraft — Sales & Marketing Playbook

> **Status:** Pre-Launch Messaging Guide
> **Version:** 2.0 — Claims must match implemented capability

## 1. Core Hook

ข้อความด้านล่างเป็น target messaging หลัง capability ที่กล่าวถึงผ่าน gate แล้ว; ก่อน Phase 6 ต้องใช้ prototype/demo qualifier และห้ามสื่อว่า release พร้อมใช้งานจริง

> ทำใบเสนอราคา ใบแจ้งหนี้ ใบเสร็จ และใบงานจากมือถือหรือคอมได้ในเว็บเดียว เปิด/ปิดบล็อกตามงานจริง ดู A4 preview ก่อนพิมพ์ และใช้งาน V1 ได้โดยไม่ต้องสมัครสมาชิก

ห้ามใช้คำว่า “จบใน 1 นาที”, “ไม่ตกขอบทุก browser”, “ถูกกฎหมาย 100%” หรือผลลัพธ์เชิงรับประกันจนมี evidence รองรับ

## 2. Target Segments

| Segment | Pain to communicate |
| --- | --- |
| Freelancers | ไม่อยากจัดหน้า Word/Excel ซ้ำและต้องการ calculation helper |
| Field contractors | ต้องออกเอกสารจากมือถือหน้างาน |
| Custom workshops | ต้องใส่รูปงาน รายการ มัดจำ และเงื่อนไขได้ยืดหยุ่น |
| Micro-SMEs | ต้องการเครื่องมือออกเอกสารที่เบากว่าระบบบัญชีเต็มรูปแบบ |

## 3. Demo Flow
1. เลือกประเภทเอกสาร
2. กรอกธุรกิจ/ลูกค้า/รายการ
3. เปิดบล็อกที่ต้องใช้ เช่น รูป WHT มัดจำ PromptPay
4. ตรวจ calculation และ A4 preview
5. กด Print เพื่อเปิด browser print dialog; ผู้ใช้เลือกพิมพ์หรือ Save as PDF ได้เองเมื่อ browser/OS รองรับ
6. แสดง JSON backup เป็น proof ของ data portability
## 4. Objection Handling

**“ต่างจากโปรแกรมบัญชียังไง?”**
DocCraft เน้นทำเอกสารเร็วและยืดหยุ่น ไม่ได้แทนระบบบัญชีเต็มรูปแบบหรือ e-Tax platform

**“ข้อมูลอยู่ไหน?”**
Free V1 เก็บ draft ใน browser เป็นหลักและมี JSON Import/Export ผู้ใช้ควร export backup โดยเฉพาะก่อนล้าง browser data หรือเปลี่ยนอุปกรณ์

**“บุคคลธรรมดาใช้ VAT ได้ไหม?”**
ระบบแยกประเภทผู้ประกอบการออกจากสถานะ VAT registration ไม่ตัดสินจากคำว่า “บุคคลธรรมดา” หรือ “บริษัท” อย่างเดียว

**“ออกใบกำกับภาษีได้ไหม?”**
Tax Invoice จะเปิดได้เมื่อ profile ระบุ VAT registered และ required fields ผ่าน validation แต่ DocCraft ไม่ควรถูกขายว่าเป็นบริการรับรอง compliance หรือ e-Tax submission

## 5. Pre-Launch Content Policy
- ใช้ prototype/demo language จน Phase 6 ผ่าน
- ห้ามโชว์ cloud sync, E-Sign, billing, Excel report เป็นของที่มีแล้ว
- ห้ามใช้ตัวเลขกำไร/ประหยัดเวลา/conversion เป็น fact
- ทุก screenshot/video ต้องตรงกับ build ที่ release จริง

## 6. Post-MVP Messaging
เมื่อ Phase 7+ ผ่าน gate แล้วค่อยเพิ่มข้อความเรื่อง cloud sync/catalog/cross-device
เมื่อ Phase 9 capability ใดผ่านจริง ค่อยเพิ่ม lifecycle conversion, reports หรือ E-Sign ตาม implementation
